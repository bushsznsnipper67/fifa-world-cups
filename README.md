# FIFA World Cups ⚽

## About the Project
This is a simple website about the FIFA World Cup, created using HTML and CSS. It provides information about the history of the tournament, past winners, and host countries.

## Features
- **Introduction:** Learn about the FIFA World Cup.
- **History:** Discover when the first World Cup took place.
- **Winners Table:** View World Cup winners from 2010 to 2026.
- **Favourite Team:** Select your favourite football team.
- **Football Question:** Answer whether you like football.
- **Submit Button:** Display your selected team and answer.

## Technologies Used
- HTML
- CSS
- JavaScript

## Teams Included
- Brazil
- Portugal
- Argentina
- France
- Spain

## How to Run the Website
1. Download or clone this repository.
2. Make sure `index.html`, `style.css`, and `images.jpg` are in the correct locations.
3. Open `index.html` in your web browser.
4. Explore the website and try the interactive features.

## Project Purpose
The purpose of this project is to learn the basics of web development using HTML, CSS, and JavaScript while exploring the history of the FIFA World Cup.
